# tray-left

Windows 시계 옆에서 Codex에 남은 양을 보는 작은 프로그램입니다.

아이콘에 마우스를 올리면 남은 비율이 나옵니다. 아이콘을 누르면 창이 열립니다. 사용량은 켤 때 한 번, Codex가 일한 뒤 90초 뒤에 한 번만 확인합니다.

큰 숫자는 지금 창에 남은 양입니다. Codex가 5시간 창을 알려 주면 그 숫자가 5시간 창이고, 한 주가 함께 오면 아래에 따로 나옵니다. 5시간 창이 없는 요금제는 그 창 하나만 보여 줍니다. 창 이름은 요금제 이름이 아니라 Codex가 보낸 창 길이를 따릅니다.

저작권은 [ju0o](https://github.com/ju0o/tray-left)에 있습니다. 라이선스는 MIT입니다.
