# Jusage

Windows 시계 옆에서 Codex에 남은 양을 보는 작은 프로그램입니다.

아이콘 한가운데에 남은 숫자가 있습니다. 마우스를 올리면 5시간 창과 한 주가 같이 나옵니다. 아이콘을 누르면 창이 열립니다. 사용량은 켤 때 한 번, Codex가 일한 뒤 90초 뒤에 한 번만 확인합니다.

큰 숫자는 더 먼저 닿는 창입니다. 5시간 창과 한 주가 함께 오면 두 칸으로 나뉩니다. 그 창이 다시 채워지는 시각은 한 줄로 나옵니다. 지난번과 다르면 얼마나 줄었는지도 한 줄로 나옵니다. 5시간 창이 없는 요금제는 그 창만 보여 줍니다. 창 이름은 요금제가 아니라 Codex가 보낸 창 길이를 따릅니다.
